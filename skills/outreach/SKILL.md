# Outreach

Use this skill for any aiascent outreach: writing emails, logging sends,
checking who has replied, or reporting on progress.

## HARD RULES
1. At the START of any outreach work: `git pull` in this repo.
2. At the END of any outreach work: `git add -A && git commit && git push`.
3. Never invent a send. Only log what was actually sent, on the day it was sent.
4. Never rewrite past log lines. Append only.

## FILES
- prospects.md — who to contact, one per line, with status
- sent-log.md — dated record of every send and every reply
- templates.md — current email templates

## DAILY TARGET
5 sends per day. Log each one the same day.

## HOW TO WRITE AN EMAIL
Read templates.md first. Keep it short. One specific reason this person,
not a generic pitch. No attachments on a first send.
